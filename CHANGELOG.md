## [0.1.0] - 2026-08-19

### Added

- The initial `create-morrowkit` project generator with interactive and
  non-interactive workflows for pnpm, npm, Yarn, and Bun.
- A production-oriented Next.js SaaS template with Supabase authentication and
  data access, protected dashboards, profiles, and row-level security.
- Optional Stripe billing, Resend transactional email, and PostHog analytics
  modules that can be excluded cleanly during generation.
- Stripe Checkout, Customer Portal, subscription synchronization, durable
  webhook processing, and plan-based entitlements.
- Sentry monitoring, environment validation, local Supabase setup, production
  deployment guidance, and reusable application states and UI components.
- Vitest, Playwright, pgTAP, ESLint, Prettier, and TypeScript quality gates,
  including CI coverage for full and reduced generated-project variants.
- Contributor, security, support, licensing, and manual release documentation.
